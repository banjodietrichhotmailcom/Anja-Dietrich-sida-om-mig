# Anja-Dietrich-sida-om-mig
Sida om mig
Jag vill göra något enkelt med mycket färg utan att vara för skrikigt.
Har ägnat mycket tid åt att leta rätt rosa, blå och gul färg men är rädd att det ändå är för mycket färg. 
Min idé var att få post-it lapparna att vändas upp snygg och lägga sig på bredden på dator och på höjden på mobilen. Men har inte lyckats med det än. 
Har också en idé om att bygga en menyrad över port-it lapparna högst upp.
