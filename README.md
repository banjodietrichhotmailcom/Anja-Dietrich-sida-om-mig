# Anja-Dietrich-sida-om-mig
En sida om mig. 
Jag vill göra något enkelt med mycket färg utan att vara för skrikigt. Har använt post-it lappar som varsin bakgrund för projekt, kontakt och om mig då jag tycker att lapparna för tankarna till idéer som får liv.  
Har ägnat mycket tid åt att leta rätt rosa, blå och gul färg för att kunna använda samma färgtema till post-it lapparna.  
Har även lagt till skuggor på äggovalerna och runt min profilbild för att det ska bli ett djup i bilden.
Interaktioner jag byggt är funktionen att när man klickar på äggovalerna så lägger sig post-it lapparna sidleds respektive på hög beroende på om man sitter vid datorn eller tittar på mobilen. Det ska heller inte spela någon roll vilken knapp man trycker på först, de lägger sig i den ordning man trycker. Jag har också med en länk till LinkedIn. Jag tyckte att det såg lite tomt ut under projekt och la därför in saker jag gjort som inte har med UX att göra men som visar min kreativa sida. Jag har lagt till alt beskrivningar på mina bilder och det ska gå att taba sig igenom sidan. När man hovrar över äggovalerna och LinkedIn-länken ska det synas. 
/Anja
